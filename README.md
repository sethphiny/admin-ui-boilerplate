# Admin Dashboard

Admin dashboard application built with React, TypeScript, and Tailwind CSS

## Tech Stack

- React 18 + TypeScript
- Vite
- React Query
- Tailwind CSS + shadcn/ui
- React Router

## Getting Started

```bash
pnpm install
pnpm dev
```

## Implemented Features

- Dashboard with dynamic stats renderer and carousel
- User management
- Wallet management
- Transaction management
- Payment management
- Admin management
- RBAC (Roles & Permissions)
- System configuration
- Balance logs
- Activity logs
- Webhooks
- Notifications
- Worker Monitoring

## Environment Variables

```env
VITE_API_BASE_URL=http://localhost:3000/v1/api
```
